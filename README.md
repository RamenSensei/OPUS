# 月の出でたらむ夜は　〜十五夜摺〜

**月出之夜 · 十五夜摺** ｜ *On Nights When the Moon Comes Out — A Fifteenth-Night Impression*

一部 3 分 56 秒的浮世绘风格动画短片，主题是中秋（日本的「十五夜・お月見」）。

十五夜，祖母以初升的明月为灯，把《竹取物语》化作纸门上的影绘；当月亮走进圆窗，她自己的影子离开身体，攀着窗格升入月中，只回头望了一眼。六十个秋天之后，当年的孩子白发苍苍，披着祖母留下的羽织独坐同一条檐廊，在一轮丝毫未老的月亮下把那一夜看完——正如辉夜姬所托：“有月亮出来的夜晚，请望向我。”

片名取自《竹取物语》中辉夜姬留给翁的信：「月の出でたらむ夜は、見おこせたまへ」（有月亮出来的夜晚，请望向我），并且故意只说了半句——另外半句要到影片第 122 秒才被写完。

## 观看

- 直接用浏览器打开 `index.html`，或打开打包好的单文件 `dist/tsukimi.html`（字体与全部脚本已内嵌，可离线观看）。

## 结构

整部片子被设计成**一张在十五夜被印出来的木版画**，印刷的过程本身就是叙事：

| 段 | 时间 | 内容 |
|---|---|---|
| 序　初摺 | 0:00–0:14 | 空白和纸上，馬連（baren）以螺旋摺出墨线主版，色版一块块落下，每一块都伴随一声「見当」的轻响；唯有月亮的位置始终留白——月亮从来不是印上去的，它是纸本身。 |
| 一　月出 | 0:14–0:40 | 巨大的山吹色月亮从芒草中升起，小夜抱着比自己还高的芒草走过月面。十五个月见团子随十五声筝音垒成 9-4-2；「お月見泥棒」偷走一个团子，祖母转头看月，假装没看见。 |
| 二　影绘·竹取 | 0:40–1:06 | 熄灭行灯，四扇纸门成了银幕：竹取翁、发光的竹节、由三寸小人长成长发少女的辉夜姬——她是纸板上“挖空”的光。祖母举起纸月亮遮住真月亮，“望月亮的脸，是不吉利的。” |
| 三　水中月 | 1:06–1:30 | 蹲踞里，孩子伸手去抓水中的月亮，月亮碎成云母；祖母用柄杓舀起一枚小小的月亮倒进她掌心，月亮从指缝间一点点漏光。祖母以「狐の窓」让她看见月亮真正的脸。 |
| 四　月在中天 | 1:30–1:58 | 仰望巨大的纸月亮：《今昔物语集》里的兔子没有东西可献，纵身跳入火中；烟在月面上凝成捣药的兔子——这是月亮上唯一被“印”上去的墨，此后每一轮月亮都带着它。 |
| 五　天之羽衣 | 1:58–2:40 | 高潮。祖母把羽织盖在熟睡的孩子身上（“请把留下的衣裳当作念想”）；无物投下的影子从纸门滑过；月亮正好停在圆窗正中时，她的影子离开身体、挺直、攀格而上——所有色版在这一刻错位，如泪眼模糊；她回头看了一眼，然后“咔嗒”一声，套版对准：她忘记了。 |
| 六　后摺 | 2:40–3:10 | 同一座庭院，六十年后用磨损的旧版再印一次：暖色版没了，天空的晕染没了，墨线断裂、纸张泛黄。只有月亮是新的。一位驼背的老人坐在檐廊上——我们以为祖母回来了，直到那根褪色的红绳出卖了她：是小夜。 |
| 七　有明之月 | 3:10–3:26 | 空荡的房间，挂轴留下一块没有褪色的方形。小夜点香；狐狸偷走最上面的团子——她转头看月，假装没看见。 |
| 结　不尽之烟 | 3:26–3:56 | 黎明的富士。烟从火口升起，在 3:34 触到月亮的边缘——全片唯一一次人间与月亮的接触；尺八补上了那句旋律缺失的最后一个音，晨钟随之响起。然后整张版画按真实颜料褪色的顺序“退印”，只剩一张白纸、一轮压印的月亮，和一枚朱印「忘れじ」（不会忘记）。 |

## 做法

- **一切都是程序绘制**：没有任何位图素材。画面是 Canvas 2D，日文诗句是真实字体的竖排 DOM 文字，配乐全部用 WebAudio 实时合成（筝、尺八、笙、琵琶、神乐铃、梵钟、铃虫、松虫、鹿威し、馬連……）。
- **版木系统**（`js/core/print.js`）：每个主镜头被“雕刻”成墨线主版 K 与色版 P1–P8、曙色版 D；同一张时间表驱动序章的摺印、第五段的错版（泪）与“咔嗒”对版（遗忘）、160 秒进入“后摺”的颠簸，以及终章按颜料褪色顺序的退印。
- **唯一的月亮**（`js/core/moon.js`）：全片只有一条连续的天体轨迹，每个镜头各自投影；月亮永远是穿透所有色版、露出和纸的“洞”。
- **声画同步**：`js/score.js` 导出 `TSUKI.CUES`（团子、见当声、捣药、钟声……），画面按同一组时间落拍。
- 每一帧都是时间的纯函数，因此可以任意拖动、逐帧导出。

## 目录

```
index.html            影片页面
css/film.css          放映室、竖排文字、控制条
fonts/                按实际用字裁剪的字体子集（SIL OFL）
js/core/              引擎：util palette brush cast paper print moon text audio engine
js/shots/             六个主镜头（A 庭院 / A′ 檐廊 / B 纸门 / C 蹲踞 / D 仰望 / E 黎明富士）
js/scenes/            九段场景
js/script.js          全片文字与段落（由 design/screenplay.json 生成）
js/score.js           配乐总谱与 TSUKI.CUES
design/               剧本（screenplay.json）、导演阐述（treatment.md）、风格与 API 文档
tools/                截图、构建、字体子集、导出视频等工具
dist/tsukimi.html     单文件版本
```

## 工具

```bash
node tools/shoot.js --seg tsuki-no-de --n 6 --sheet     # 截取某一段的若干帧并拼成联系表
node tools/shoot.js --times 21,147,232 --w 1920         # 截取指定时刻（全分辨率）
node tools/build.js                                     # 打包 dist/tsukimi.html（单文件）
node tools/fonts.js                                     # 重新生成字体子集
node tools/score-test.js                                # 离线渲染整部配乐并检查电平
FFMPEG=/path/to/ffmpeg node tools/render-video.js       # 导出 MP4（H.264 + AAC）
node tools/script-from-screenplay.js                    # 由剧本重新生成 js/script.js
```

截图与导出工具需要 Node 22 与 Playwright（Chromium）；导出视频需要带 libx264 的 ffmpeg。
